# Code of Conduct

## Our commitment

Everyone participating in Daisy's repository is expected to help create a
respectful, welcoming, and constructive environment, regardless of experience,
identity, background, or viewpoint.

## Expected behaviour

- Communicate respectfully and assume good intent.
- Give specific, constructive feedback about the work rather than the person.
- Accept corrections gracefully and help newcomers understand the project.
- Respect privacy, intellectual property, and the project's licensing terms.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, sexualised attention,
doxxing, spam, and deliberate disruption are not tolerated.

## Enforcement

The repository owner may edit or remove contributions and restrict or ban
participants whose behaviour is inappropriate, threatening, offensive, or
harmful. Incidents should be reported privately through a contact option on the
repository owner's GitHub profile. Reports will be reviewed in confidence as
far as reasonably possible.

This code applies in all project spaces and whenever someone publicly
represents the project.
