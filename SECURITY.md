# Security Policy

## Supported version

Only the current state of the `main` branch is actively maintained. Historical
commits, branches, builds, and save formats may no longer receive fixes.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security
tab when available. If it is not available, contact the repository owner
privately through a contact option on their GitHub profile.

Include a clear description, affected files or versions, reproduction steps,
and the potential impact. Reports will be acknowledged and assessed as time
allows; this personal project does not currently provide a guaranteed response
or remediation timeline.
